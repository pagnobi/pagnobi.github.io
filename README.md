# pagnobi.github.io

Serves `/.well-known/assetlinks.json` at the root of pagnobi.github.io. It proves the Arcane Tricks
Quest app (`com.pagnobi.arcanetricks`) belongs to this site, so it opens full-screen without a browser bar.
The home page redirects to the game at https://pagnobi.github.io/arcane-tricks/.
